# Motorica Kart — App Store review record for 1.0 (28)

## Review Notes (English)

Motorica Kart is a permanent two-mode application maintained by MOTORICA
RESEARCH LLC. It is based on the open-source SuperTuxKart engine; the upstream
project, licenses, authors and our complete corresponding source are disclosed
in the app and at the URLs below.

**Direct launch / Standalone Mode.** Opening the app icon starts Motorica
Training Hub, not the standard SuperTuxKart menu. This standalone game works
offline with touch or device-tilt controls. It contains a Motorica-specific
night island, six entry points to one fixed three-lap Motorica Signal Circuit,
and the recolored Motorica Kiki character for the player and seven AI
opponents. Kart, track, championship and character selection are not exposed.

**Motorica Start Mode.** A valid `motorica-stk://` launch from the separately
reviewed Motorica Start app enables the local device-signal controller and
connection-loss pause/recovery behavior. A fresh App Group value alone cannot
enable this mode. If the optional full content catalog is absent, the app shows
its exact size and asks for confirmation before downloading it.

The additional catalog contains only models, textures, music, sounds and
declarative game data. It contains no executable code, frameworks, dynamic
libraries, JavaScript, WebAssembly or AngelScript. All required C/C++,
Objective-C++ and AngelScript is inside the reviewed app. Build 28 embeds a
pinned release URL, exact byte size and SHA-256. The installer rejects unsafe
paths, symbolic links and unsupported file types and activates a verified
package atomically.

The full mode is a documented product feature even though interactive device
control requires Motorica Start and compatible hardware. We provide two review
videos: (1) the complete standalone flow, and (2) Motorica Start launch,
user-confirmed content download, live device signals, driving, connection loss
and recovery.

## Проверочный сценарий

1. Запустить Motorica Kart собственным ярлыком без Motorica Start и сети.
2. Нажать «Играть», проехать по Motorica Night Island и открыть любую из
   шести точек — каждая запускает Motorica Signal Circuit.
3. Проверить 3 круга, 8 участников Motorica Kiki, кнопки «Повторить» и
   «Вернуться на остров».
4. Закрыть игру. В Motorica Start подключить совместимое устройство и открыть
   Motorica Kart из раздела игр.
5. Подтвердить загрузку полного каталога, дождаться проверки и установки.
6. Проверить полный каталог, управление сигналами, паузу при потере BLE и
   продолжение после восстановления.
7. Снова запустить ярлыком: приложение обязано открыть только Training Hub,
   даже если полный каталог уже установлен.
