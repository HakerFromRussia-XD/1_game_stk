The repository's multitouch dialog also contains Motorica EMG steering settings. Those are existing project-specific additions, **not original FLUXARA_DRIFT feature parity**, and should not be copied into public Fluxara settings by accident.

Recommended next design scope: retain the two existing cards, add separately approved Audio volumes / Controls / Graphics / Interface sections. Preserve the original application and persistence paths above; changing the presentation does not justify resetting existing preferences.
