Game support

Super Tux Kart for Motorica

Motorica-adapted SuperTuxKart build with standard touch controls and local Motorica Start game-control integration.

Need help?

For installation, launch, or Motorica Start connection questions, contact Motorica support and include your device model, iOS version, and app version.

How the game is used

Launch

The game is distributed as a separate iOS application. Motorica Start can open the installed game and activate local game-control data sharing on the same device.

Controls

The game supports standard touch controls. When used with compatible Motorica devices through Motorica Start, EMG control data can be used for steering.

Before contacting support

  • Make sure Motorica Start is installed and updated.
  • Make sure the prosthetic device is connected in Motorica Start before launching the game.
  • If the game cannot receive control data, close the game, reopen Motorica Start, reconnect the device, and launch the game again.
  • If the issue persists, include screenshots, approximate time of the issue, iOS version, Motorica Start version, and Super Tux Kart for Motorica version in your support request.
