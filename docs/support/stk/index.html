Game support

Motorica Kart

A permanent standalone training game and a Motorica Start companion mode with local device-signal control.

Need help?

For installation, launch, or Motorica Start connection questions, contact Motorica support and include your device model, iOS version, and app version.

How the game is used

Standalone mode

Opening the icon starts Motorica Training Hub. Its night island and signal circuit work offline with touch or motion control and do not require Motorica Start, BLE, an account, or the optional full catalog.

Motorica Start mode

A launch from Motorica Start activates local EMG-derived control, connection-loss pause behavior, and the optional full SuperTuxKart content catalog. The catalog is downloaded only after confirmation and contains game resources, not executable code.

Before contacting support

  • Make sure Motorica Start is installed and updated.
  • Make sure the prosthetic device is connected in Motorica Start before launching the game.
  • If the game cannot receive control data, close the game, reopen Motorica Start, reconnect the device, and launch the game again.
  • If the full catalog is not installed, confirm the displayed download size and keep the app open until verification and installation finish.
  • If the issue persists, include screenshots, approximate time of the issue, iOS version, Motorica Start version, and Motorica Kart version in your support request.
