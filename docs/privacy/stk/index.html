Privacy policy

SuperTuxKart for Motorica

This policy explains what data is processed by the Motorica-adapted game build and how the local Motorica Start integration works.

Last updated

August 6, 2026

Summary

No tracking

SuperTuxKart for Motorica does not include Motorica advertising or cross-app tracking SDKs.

Motorica control data stays local

Motorica Start control snapshots, including EMG-derived input, are exchanged locally on the same device and are not uploaded to Motorica servers by the game.

Local game-control data

When the game is launched from Motorica Start, Motorica Start may share local control snapshots with the game on the same iOS device. These snapshots can include connection state and EMG-derived control levels used for gameplay input.

This data is used only to control the game while it is running. The game does not transmit Motorica control snapshots to Motorica servers.

Optional online features

SuperTuxKart contains optional internet features inherited from the upstream project, such as news, add-ons, online accounts, and multiplayer. If the user enables or uses these features, the game may communicate with SuperTuxKart or multiplayer servers and process the information required for the requested feature.

These upstream online features are separate from the local Motorica Start controller integration and are governed by the notices shown in the game and the applicable server policies.

Data collection

  • The Motorica controller integration does not collect names, email addresses, phone numbers, location, contacts, photos, health records, or payment information.
  • We do not sell personal data.
  • We do not use third-party advertising SDKs for Motorica advertising or tracking in this Motorica game build.
  • Apple may process App Store, TestFlight, crash, purchase, and device information under Apple policies when the app is installed or tested through Apple services.
