Privacy policy

Super Tux Kart for Motorica

This policy explains what data is processed by the Motorica-adapted game build and how the local Motorica Start integration works.

Last updated

June 25, 2026

Summary

No tracking

Super Tux Kart for Motorica does not track users across apps or websites and does not include advertising identifiers for tracking.

No analytics by the game

The Motorica game build does not collect analytics, gameplay telemetry, EMG control values, or personal data for Motorica servers.

Local game-control data

When the game is launched from Motorica Start, Motorica Start may share local control snapshots with the game on the same iOS device. These snapshots can include connection state and EMG-derived control levels used for gameplay input.

This data is used only to control the game while it is running. The game does not transmit this control data to Motorica servers.

Data collection

  • We do not collect names, email addresses, phone numbers, location, contacts, photos, health records, or payment information in this game.
  • We do not sell personal data.
  • We do not use third-party advertising SDKs in this Motorica game build.
  • Apple may process App Store, TestFlight, crash, purchase, and device information under Apple policies when the app is installed or tested through Apple services.
