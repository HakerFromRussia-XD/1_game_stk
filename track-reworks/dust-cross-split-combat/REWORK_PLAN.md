## 3. Референсы → визуальные цели (с ассетами из FLUXARA_TRACK_ASSET_POOL.json)

Ниже каждый пункт имеет ссылку на конкретный реф и конкретные ID пула. Пул: 450 объектов, 72 текстуры, физический пак `FLUXARA_TRACK_ASSET_PACK/`.

### Реф-01 — Дёрт-арена с трамплинами (центр внимания: стартовая чаша)
Цели: тёплый оранжево-песчаный дёрт-грунт на склонах чаши; решётчатые трамплины с шевронами; красно-белые бетонные блоки по периметру; трибуны с тентами (красный/жёлтый/синий); флажки; конусы; свет-мачты; небо чистое голубое.
- `ski-dash-red-white-concrete-barrier` (tier adapt; геометрия `fluxara_driftlib_concreteBarrier_a_main.spm` из fluxara-user-canyon-42; текстура `canyon-concrete-barrier-diffuse` → `FLUXARA_TRACK_ASSET_PACK/textures/2bfc8d0e18bae3a1/concrete_barrier_diffuse.png`) — периметровые блоки красно-белые, уже согласованы с геймплей-периметром лёд… здесь: **дёрт-периметр**, ghost-размещение по scene.xml не трогаем.
- Текстуры грунта: держим родные слоты SPM (`fluxara_drift_generic_sand_a/b`, `grassA/B`, `runway_a`, `lama_road_a`) — **перекраска только там, где слот реально виден**, без изменения UV/геометрии; при несовпадении палитры создаём seamless-варианты по правилу 3×3 и регистрируем в пуле.
- `shared-genericskybox-top/east/west/south/north/bottom` (tier direct, cats `sky,daytime,canyon`) — чистое дневное небо вместо тёмного тумана; в scene.xml fog/sun **не редактируем** на этом пасе (визуал неба — через замену текстур бокса, не через scene.xml).
- Свет-мачты/трамплины: в пуле готовых нет → авторим новые, регистрируем (tier authored), используя `shared-greenhill-fluxara_drift_lightGrayMetal_a` как материал металла.

### Реф-02 — Серпантин у водопада (красные скалы)
Цели: массивные красно-оранжевые скальные столовые формы с «лепёшечной» скульптурой; деревянный мост; водопад с бирюзовой водой; дорога светлого дёрта с красно-белым бордюром; кактусы/зелень.
- `canyon-cascade-shelves` (adapt; полки `FD_CascadeRockShelf`; материалы `Fluxara_PaintedSandstone`, snowrock) — скальные полки у водопада.
- `canyon-split-waterfalls` (adapt; `FD_UpperCascadeFlow`,`FD_LowerCascadeFlow`; текстура `canyon-flow-texture` → `fluxara_water_flow.png`) — двухчастный водопад.
- `canyon-arched-bridge` + `canyon-bridge-assembly` (adapt; деп. `Fluxara_BridgeHoneyWood`,`Fluxara_BridgeSandstone`, атлас) — деревянный мост через промоину.
- `canyon-cliff-garden-details` (adapt; 84 meshes; деп. `Fluxara_DetailLeaf0/1/2`, атлас) — зелень на скалах. Осторожно: в Ski Dash их забраковали как «парящие кусты» — здесь ставим только на скальные уступы, не в воздухе.
- `canyon-main-atlas` (adapt; `fluxara_canyon_atlas.png`, SHA `98a9a21bb82714e2…`) — атлас скал; для реф-02 палитра краснее зимней версии → вероятно, потребуется новый seamless-вариант атласа (регистрация отдельным ID).
- Кактусы: в пуле нет → новые авторские (authored), low-poly.

### Реф-03 — Дорога над облаками (высотный участок)
Цели: серый асфальт с белой разметкой (родной слот `fluxara_driftlama_road_a.png` — виден здесь), деревянные ограждения-столбики, красно-белые блоки, гирлянды треугольных флажков, жёлтые шеврон-знаки поворотов, скалы с плоскими «ступенчатыми» торцами, море облаков, высокая скала-башня слева с мостом.
- `canyon-bridge-pennants` (adapt; `FD_FlagPole`,`FD_BridgeClothFlag`; текстуры `Fluxara_DetailFlag0..3` в атласе) — гирлянды флажков.
- `canyon-eastern-arched-bridge-v2`/`ski-dash-eastern-arched-bridge-v2` (authored, башня+мост силуэт) — дальняя башня с мостом (слева на рефе).
- Ограждения-столбики: донор `Fluxara_Canyon_RoadsideFences` (коллекция донора, 20+ объектов) — аппендим.
- Шеврон-знаки: `shared-greenhill-fluxara_drifttex_directionSign_a` + `directionPattern_a` (direct) — база; жёлтый вариант — при несовпадении авторим.
- Облака-море: плоскость/карточки с новым seamless-облачным тайлом (authored; правило 3×3; без витиеватых краёв).
- Асфальт: слот `fluxara_driftlama_road_a.png` — перекраска альбедо допустима без смены UV; при необходимости — новый seamless-вариант.

### Реф-04 — Каталожный ландшафт (общая проверка композиции)
Служит сводной приёмкой: крупные красные месы на горизонте, дёрт-арена в центре, мост/арки, водопады. Месы собираем из `ski-dash-canyon-mesa-{0,1,2}-{rock,cap}` (rock tier=adapt, cap tier=authored; пачSource `…FLUXARA_Track_Asset_Library.blend#Object/SkiDash_SnowCliff_0{1,2,3}_…`) — но **требуют reskin**: у них зимняя шапка; для дёрт-каньона шапки заменяются на песчаник (новые материалы, не трогая меш-геометрию).
