# Approved Garage artwork

Approved in the design conversation on 2026-09-18. These PNGs are the
individual assets used in the approved Figma Garage table, not whole-row
screenshots. Preserve their transparency and aspect ratios.

- `fluxara-panel-transparent.png`: clean panel, with transparent outer corners.
- `fluxara-{weight,speed,accel,nitro}.png`: four separately positioned icons.
- `fluxara-segment-{coral,cyan,purple,yellow}.png`: one filled segment each.
- `fluxara-segment-empty.png`: one unfilled segment.

Labels and the selected kart name remain separate, dynamic UI elements.
Segment counts must reflect the selected kart's engine characteristics;
the ten filled segments shown in the design are illustrative only.

The assets are staged here for UI integration. Their presence does not
mean that the current Garage renderer already uses the approved design.
