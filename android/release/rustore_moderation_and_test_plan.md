## Инструкция модератору

STK не имеет отдельного ярлыка и запускается из приложения «Моторика Старт».

1. Установить совместимую тестовую сборку «Моторика Старт», подписанную сертификатом Motorica.
2. Установить STK из RuStore.
3. Открыть «Моторика Старт».
4. Перейти в раздел «Аккаунт → Игры».
5. Запустить SuperTuxKart.
6. Убедиться, что игра открылась в горизонтальной ориентации.
7. Выйти из игры и убедиться, что возврат в «Моторика Старт» выполнен корректно.

## План тестирования

### 1. Статическая проверка APK

- Версия соответствует `1.0.14 (1014)`.
- Системное название соответствует `SuperTuxKart`.
- Разрешение `android.permission.REQUEST_INSTALL_PACKAGES` отсутствует.
- Фильтры `MAIN` и `LAUNCHER` отсутствуют.
- Activity `com.motorica.games.stk.SuperTuxKartActivity` доступна только вызывающей стороне с разрешением `com.motorica.gamecontrol.permission.CONTROL_GAME`.
- Подпись APK валидна и совпадает с подписью «Моторика Старт».

### 2. Установка и обновление

- Выполнить чистую установку STK из тестового канала RuStore.
- Убедиться, что отдельный ярлык STK не появился.
- Проверить название SuperTuxKart в системном списке приложений.
- Установить `1.0.13`, создать локальные игровые данные и обновить до `1.0.14`.
- Убедиться, что обновление прошло без конфликта подписи и игровые данные сохранились.

### 3. Интеграция с «Моторика Старт»

- «Моторика Старт» определяет установленный STK.
- Кнопка запуска открывает `SuperTuxKartActivity`.
- Попытка запуска activity приложением без signature-разрешения отклоняется.
- Выход и системная кнопка «Назад» корректно возвращают пользователя.
- Повторный запуск работает без перезапуска устройства.

### 4. Игра

- Запускается гонка.
- Работает сенсорное управление.
- Работает управление сигналами поддерживаемого протеза.
- Пауза, сворачивание и восстановление не завершают игру аварийно.
- Блокировка и разблокировка экрана не нарушают состояние игры.
- После установки игра запускается без подключения к интернету.

## Критерии приёмки

- Ни один сценарий STK не запрашивает разрешение на установку неизвестных приложений.
- Установка и обновление STK выполняются средствами RuStore.
- Отдельный ярлык отсутствует.
- Запуск из «Моторика Старт» работает.
- APK проходит проверку подписи, версии и разрешений.
